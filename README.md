# PageTurn — Storybook Library
A responsive Wattpad-inspired storybook website for an ITE 1 project.

## Files
- `index.html` — home page, search, filters, story cards, modal details
- `story.html` — reader page, one chapter per story
- `css/style.css` — shared external stylesheet
- `js/stories.js` — 30 original stories and metadata
- `js/app.js` — library search, genre filters, sorting, likes/saved stories, modal, dark/light mode
- `js/reader.js` — story rendering, reading progress, font controls, save button
- `images/` — 30 locally stored SVG book-cover images

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser. For best results, use VS Code Live Server.
3. Click any cover or “Read story” to open its single-chapter reading page.

## Functional features
- 30 different stories across multiple genres
- Search by title, author, genre, or synopsis
- Genre filters and sorting
- Responsive navigation and page links
- Like/save stories persisted with localStorage
- Story details popup
- Dark/light mode persisted with localStorage
- Reader font-size controls and reading progress
- Locally stored cover images (SVG)
